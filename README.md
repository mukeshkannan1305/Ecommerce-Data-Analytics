# Ecommerce Data Analytics Project

## Project Overview

This project analyzes e-commerce sales, profitability, customer behavior, product performance, and regional business performance using Python, SQL, and Power BI.

## Objectives

* Analyze sales and profit trends.
* Understand customer segments and demographics.
* Identify top-performing products.
* Compare sales and profitability across regions.
* Present business insights through interactive dashboards.

## Tools and Technologies

* Python
* Pandas
* SQL
* Oracle SQL
* Microsoft Power BI
* DAX


## Dataset

The project uses cleaned e-commerce datasets containing sales transactions, customer information, product details, and location information.

The sales dataset contains approximately 12,000 records.

## Power BI Dashboards

### 1. Sales & Profit Analysis

Analyzes sales, profit, and sales performance over time.

### 2. Customer Analytics

Explores customer demographics, customer segments, and customer distribution.

### 3. Product Analytics

Evaluates product sales, profitability, and product performance.

### 4. Location & Regional Analysis

Compares sales and profit across locations and regions.

## Project Workflow

1. Data cleaning and preparation using Python.
2. Data analysis using SQL.
3. Data modeling and measure creation using Power BI and DAX.
4. Dashboard development and interactive visualization.
5. Business performance analysis.

## Key Outcomes

* Developed four interactive Power BI dashboards.
* Analyzed 12,000 sales records.
* Examined customer, product, and regional performance.
* Created visual reports to support data-driven business decisions.
